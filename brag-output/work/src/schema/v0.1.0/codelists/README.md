# Codelists for canonical schema 0.1.0

One JSON file per codelist, named `<codelist>.json`:

    {"codelist": "entity_type", "version": "2025-04-28", "values": [{"code": "...", "label": "..."}]}

No official codelists are loaded yet. Until a codelist file exists, every value of a
field bound to it reports `codelist_unverified` (never valid).
